# Python.ComputerVisionProject.Real-TimeObjectDetection
This project aims to develop a real-time system that detects, tracks, and counts vehicles in urban traffic video streams using deep learning. It integrates YOLOv8 for object detection and DeepSORT for multi- object tracking. 
Bu proje, derin öğrenme kullanarak şehir içi trafik video akışlarındaki araçları gerçek zamanlı olarak tespit etmeyi, takip etmeyi ve saymayı amaçlamaktadır. Proje, nesne tespiti için YOLOv8 ile çoklu nesne takibi için DeepSORT algoritmalarını bir araya getirmektedir.
